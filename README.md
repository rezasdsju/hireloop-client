# HireLoop - A Job Portal

HireLoop is a web application where users can search for jobs, and recruiters or companies can post hiring opportunities. All job posts are reviewed and controlled by an admin.

This repository contains the frontend of the application.

## Live Demo

[https://hireloop-jobs-board.vercel.app](https://hireloop-jobs-board.vercel.app)


## Features

- Responsive navbar with mobile menu
- Light and dark theme toggle
- User registration and sign in with email and password
- User roles: job seeker, recruiter and admin
- Profile menu with sign out
- Role-based dashboards for recruiter, seeker and admin
- Job posting and deletion for recruiters
